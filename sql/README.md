# SQL Analysis

This folder contains the SQL exploration performed before building the Power BI dashboard.

## Files

- **01_data_understanding.sql**
  - Review raw datasets
  - Validate schema consistency
  - Merge monthly files
  - Check missing values and duplicates

- **02_data_exploration.sql**
  - Explore booking error distribution
  - Analyze providers and hotels
  - Identify patterns in the raw data

The insights from these exploratory queries informed the data model and dashboard design developed in Power BI.
